# 💰 Expense Tracker

I built this **Expense Tracker  with Python** that helps users record, manage, search, and analyze their daily expenses.

## 📌 About the Project

This project was created to practice Python programming concepts by building a real-world application.

The Expense Tracker allows users to add expenses with details such as category, amount, description, and date. It also provides different options to view and analyze the stored expenses.

## ✨ Features

- ➕ Add a new expense
- 📋 View all expenses
- 💰 Calculate total amount spent
- 📈 Find the highest expense
- 📉 Find the lowest expense
- 🔍 Search expenses by category
- 🗑️ Delete an expense
- ✏️ Update an existing expense
- 📅 View expenses by month
- 📊 View category-wise expense summary
- 💾 Save expenses using JSON
- 🔄 Load previously saved expenses
- ✅ Input validation for amounts and dates
